# Python OOP Lists & Dictionaries Lab

## Overview

This project demonstrates the use of **Object-Oriented Programming (OOP)**, **Lists**, and **Dictionaries** in Python by implementing an **Employee Salary System**.

The system allows users to:

* Add employee records
* Display all employees
* Search for an employee by name
* Increase an employee's salary
* Store employee data using dictionaries inside a private list

---

## Features

### Add Employee

Users can add employee details including:

* Name
* Position
* Salary

### Display Employees

View all employee records stored in the system.

### Search Employee

Search for an employee by entering their name.

### Increase Salary

Increase an employee's salary using the `+=` operator.

### Input Validation

Ensures salary values are valid numeric inputs.
